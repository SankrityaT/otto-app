# Otter device (Raspberry Pi)

The otter is a desk buddy that sits at a work station. It takes a photo when the student asks for one and speaks each step out loud, using the same API as the web app.

**Status:** being written. The demo uses a phone camera; this client has not been tested on a Raspberry Pi yet.

Planned hardware: Raspberry Pi 4 (2 GB), Raspberry Pi Camera Module 3 Wide, a small USB or 3.5 mm speaker.
